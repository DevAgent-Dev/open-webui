# DevAgent.Dev Branding Assets

This directory contains the **DevAgent.Dev** corporate-identity assets used by this
deployment: favicons, logos, splash images, app icons, and web-app-manifest icons.

## Source of truth

- Identity guidelines: `~/DevAgent.Dev/branding/DevAgent.Dev-Branding-CI.md` (v2.0, September 2026)
- Approved artwork: `~/DevAgent.Dev/brand-assets/`
- Asset usage notes: `~/DevAgent.Dev/brand-assets/README.md`

Assets here are generated by `scripts/brand/gen_brand_assets.py` from the official
transparent colour and reverse artwork. The script only copies or resizes approved
files; it does not remove backgrounds, reconstruct the mark, recolour it, or change
its proportions. The square app icon is used for favicons and installable-app icons,
the symbol is used for splash screens, and approved lockups are retained for branded
UI surfaces.

| File                                                             | Purpose                                           |
| ---------------------------------------------------------------- | ------------------------------------------------- |
| `favicon.png`, `favicon-96x96.png`, `favicon.ico`, `favicon.svg` | Browser tab / sidebar app icon                    |
| `apple-touch-icon.png`                                           | iOS home-screen icon                              |
| `logo.png`, `web-app-manifest-*.png`                             | Approved square PWA icon with maskable safe zone  |
| `splash.png`                                                     | Colour symbol for light surfaces                  |
| `splash-dark.png`                                                | Official white reverse symbol for dark surfaces   |
| `brand/devagent-mark.png`                                        | Transparent colour symbol, 512 px wide            |
| `brand/devagent-compact*.png`                                    | Compact colour and reverse website-header lockups |
| `brand/devagent-horizontal.png`                                  | Primary horizontal lockup with bilingual slogan   |

Brand colours: Trust Blue `#0B57D0`, Growth Green `#00C781`, Focus Navy
`#0F172A`, Balance Gray `#E5E7EB`, and White `#FFFFFF`. Type: Inter or Arial
(Latin), Noto Sans Thai or Sarabun (Thai).
